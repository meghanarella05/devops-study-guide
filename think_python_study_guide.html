The Way of the Program

Programs, Python basics, types of errors
Key What is a Program? ▶

A program is a sequence of instructions that specifies a computation. All programs use these building blocks:

  • Input — get data from keyboard, file, network
  • Output — display on screen, save to file
  • Math — arithmetic operations
  • Conditional execution — check conditions, run appropriate code
  • Repetition — perform action repeatedly

Trap 3 Types of Errors ▶
  • Syntax error — structure is wrong; Python can't even parse it. Program won't run.
  • Runtime error — error while running (also called exceptions). E.g., dividing by zero.
  • Semantic error — program runs but does the wrong thing. Hardest to find!

Key Fruitful vs Void Functions ▶
  • Fruitful function — returns a value (e.g., math.sqrt(5))
  • Void function — does something but returns None (e.g., print())
If you call a void function and try to use its result, you get None. Example: result = print('hi') → result is None.

Key Recursion ▶

A function that calls itself. Must have a base case (stops recursion) and a recursive case.

def countdown(n):
    if n <= 0:             # base case
        print('Blastoff!')
    else:
        print(n)
        countdown(n-1)    # recursive case
Infinite recursion (no base case) → RuntimeError: maximum recursion depth exceeded.

n % 2 gives remainder: 0 if even, 1 if odd. n // 2 is floor division.

Code Return Values ▶ 
def absolute_value(x):
    if x < 0:
        return -x
    else:
        return x
Once return is hit, the function exits immediately. Code after it doesn't run (dead code).
Key Boolean Functions & Guardian Pattern ▶ 
def is_divisible(x, y):
    return x % y == 0   # returns True/False

def factorial(n):
    if not isinstance(n, int):   # guardian
        print('error: must be int')
        return
    if n == 0: return 1
    return n * factorial(n-1)

Key Memoization & Global Variables ▶

Memoization — cache previously computed results to avoid redundant work.

known = {0: 0, 1: 1}

def fibonacci(n):
    if n in known:
        return known[n]
    res = fibonacci(n-1) + fibonacci(n-2)
    known[n] = res
    return res

Chapter 16

Classes & Functions

Pure functions, modifiers, prototype & patch vs designed development
Key Pure Functions vs Modifiers ▶
  • Pure function — does NOT modify its arguments; returns a new value. Easier to reason about.
  • Modifier — changes the object passed in. Side effects visible to caller.
# Pure function
def add_time(t1, t2):
    result = Time()
    result.hour = t1.hour + t2.hour
    return result  # new object, t1/t2 unchanged

# Modifier
def increment(time, seconds):
    time.second += seconds  # changes time in place!

Invariant: condition that should always be true (e.g., 0 ≤ minutes < 60). Use assert to check.

Chapter 17

Classes & Methods

self, __init__, __str__, operator overloading, polymorphism
Code Methods, __init__ & __str__ ▶ 
class Time:
    def __init__(self, hour=0, minute=0, second=0):
        self.hour = hour
        self.minute = minute
        self.second = second

    def __str__(self):
        return '%.2d:%.2d:%.2d' % (
            self.hour, self.minute, self.second)

    def __add__(self, other):   # + operator
        secs = self.to_seconds() + other.to_seconds()
        return Time.from_seconds(secs)

t = Time(9, 45)
print(t)         # 09:45:00  (calls __str__)
t2 = Time(1, 35)
print(t + t2)    # 11:20:00  (calls __add__)
Key Polymorphism & Type-based Dispatch ▶

Polymorphism — same function/method works with multiple types.

Type-based dispatch — use isinstance() to call different code based on type.

def __add__(self, other):
    if isinstance(other, Time):
        return self.add_time(other)
    else:
        return self.increment(other)

Key special methods: __init__, __str__, __add__, __lt__, __len__, __radd__

Chapter 18

Inheritance

Subclasses, method overriding, class attributes, isinstance
Code Inheritance Basics ▶ 
class Card:
    suit_names = ['Clubs','Diamonds','Hearts','Spades']
    rank_names = [None,'Ace','2','3',...,'King']

    def __init__(self, suit=0, rank=2):
        self.suit = suit
        self.rank = rank

    def __str__(self):
        return '%s of %s' % (
            Card.rank_names[self.rank],
            Card.suit_names[self.suit])

    def __lt__(self, other):
        t1 = self.suit, self.rank
        t2 = other.suit, other.rank
        return t1 < t2

class Deck:
    def __init__(self):
        self.cards = [Card(s, r)
            for s in range(4)
            for r in range(1, 14)]

class Hand(Deck):     # inherits from Deck
    def __init__(self, label=''):
        self.cards = []
        self.label = label
Key Class vs Instance Attributes ▶
  • Class attribute — defined in class body, shared by all instances (e.g., Card.suit_names)
  • Instance attribute — defined with self.x, belongs to one object

Subclass inherits all parent methods. Can override by defining method with same name.

Data encapsulation — discover attributes needed from functions you write, then build the class around them.

Trap Debugging Strategies (Appendix A) ▶

Syntax Errors

  • Missing colon at end of def, if, for, while
  • Using = instead of == in condition
  • Unclosed parentheses/brackets
  • Wrong indentation (mixed tabs and spaces)
  • Using keyword as variable name

Runtime Errors

  • NameError — variable doesn't exist (wrong scope?)
  • TypeError — wrong type, wrong number of args
  • KeyError — dict key doesn't exist
  • AttributeError — object doesn't have that attribute
  • IndexError — index out of range

Semantic Errors

Program runs but gives wrong answer. Add print() statements to trace values.

Code OOP Pattern Summary ▶ 
class Animal:
    species = 'Unknown'       # class attribute

    def __init__(self, name):
        self.name = name        # instance attribute

    def __str__(self):
        return self.name

    def speak(self):
        raise NotImplementedError

class Dog(Animal):              # inherits Animal
    species = 'Canis lupus'    # override class attr

    def speak(self):            # override method
        return 'Woof!'

d = Dog('Rex')
print(d)              # Rex
print(d.speak())      # Woof!
isinstance(d, Animal) # True
Quiz Final Exam Practice Questions ▶
Q: What does list(zip([1,2],[3,4])) return?
[(1, 3), (2, 4)]
Q: What is the difference between == and is?
== checks if values are equal. is checks if two variables refer to the exact same object in memory.
Q: What does [x**2 for x in range(5)] return?
[0, 1, 4, 9, 16]
Q: Why can't you use a list as a dictionary key?
Lists are mutable and unhashable. Dict keys must be hashable (immutable). Use a tuple instead.
Q: What does shallow copy vs deep copy mean?
Shallow (copy.copy()) copies the object but embedded objects are still shared (same references). Deep (copy.deepcopy()) copies everything recursively — fully independent.
Q: What is __init__ for?
It's the constructor/initializer method called automatically when you create a new instance with MyClass(). Sets up instance attributes.
Q: What is the output? d = {'a':1}; d.get('b', 99)
99 — key 'b' doesn't exist, so get() returns the default value 99.
Q: What's the Big-O of searching a sorted list with bisect?
O(log n) — bisection search halves the search space each step.
